แตะปุ่มคัดลอก แล้วสลับไปวางในหน้าแลกโค้ด Garena หรือเปิดระบบนับถอยหลังอัตโนมัติ

เปิดหน้าแลกโค้ด Garena ↗
💡 ต้องการสคริปต์ช่วยกรอกอัตโนมัติในหน้า Garena?
ตัวช่วยกรอกอัตโนมัติยังไม่เริ่ม
  1. 1
    ติดตั้งบุ๊กมาร์ก "DF ช่วยกรอก" ครั้งเดียวต่อเครื่อง คอมพิวเตอร์: ลากปุ่มนี้ไปวางบนแถบบุ๊กมาร์ก DF ช่วยกรอก (ไม่เห็นแถบ กด Ctrl+Shift+B) มือถือ / ไอแพด / แท็บเล็ต: แล้วทำตาม "วิธีติดตั้งบนมือถือ" ด้านล่าง
  2. 2
    เปิดหน้าแลกโค้ดจากปุ่มนี้ คิวทั้งหมดถูกส่งไปกับหน้านั้น · ยังไม่ได้เข้าสู่ระบบ Garena ก็เข้าด้วยตัวคุณเองในหน้านั้น
  3. 3
    ในหน้าแลกโค้ด กดบุ๊กมาร์ก "DF ช่วยกรอก"แถบสีทองขึ้นบนหน้าแลกโค้ด = ตัวช่วยทำงานแล้ว
  4. 4
    ระบบใส่โค้ดให้ → กดยืนยันอัตโนมัติ → อ่านผล จดให้ พัก แล้วใส่โค้ดถัดไประบบทำงานวนจนหมดคิว ทุกขั้นตอนอัตโนมัติโดยไม่ต้องกดเอง
ใช้บนมือถือ / ไอแพด / แท็บเล็ต

iPhone / iPad (Safari) — ① กดแชร์ → "เพิ่มบุ๊กมาร์ก" (หน้าไหนก็ได้) ตั้งชื่อ DF ช่วยกรอก ② เปิดรายการบุ๊กมาร์ก → "แก้ไข" → แตะบุ๊กมาร์กนั้น → ลบที่อยู่เดิม วางโค้ดที่คัดลอก → เสร็จ ③ ในหน้าแลกโค้ด เปิดรายการบุ๊กมาร์กแล้วแตะ "DF ช่วยกรอก" · บนไอแพดเปิด "แสดงแถบรายการโปรด" แล้วแตะจากแถบได้เลย

Android (Chrome) — ① กด ⋮ → ☆ (บุ๊กมาร์กหน้าไหนก็ได้) → "แก้ไข": ชื่อ dfhelp · URL ลบของเดิมแล้ววางโค้ดที่คัดลอก ② ในหน้าแลกโค้ด แตะแถบที่อยู่ พิมพ์ dfhelp แล้ว แตะรายการบุ๊กมาร์กที่ขึ้นมา (อย่ากด Enter)

บนมือถือทุกอย่างจบในแท็บเดียว: ตัวช่วยถือคิวไว้เอง · เสร็จแล้วกด "กลับศูนย์โค้ด" บนแถบสีทอง ผลทั้งหมดจะถูกส่งกลับมาจดที่นี่

ไม่มีโค้ดในคิว — กด "อนุมัติ" ที่โค้ดในรายการด้านล่าง หรือวางโค้ดใหม่
เปิดหน้าแลกโค้ด ↗

ปุ่มด้านล่างนี้ แค่จดผล ไม่ได้ส่งโค้ด — ใช้เมื่อคุณวางโค้ดในหน้าแลกของ Garena เองแล้ว (ตัวช่วยกรอกจดผลให้เองอยู่แล้ว) · จดผิดกด "เข้าคิวใหม่" ที่แถวนั้นในรายการ

เพิ่มโค้ดวางได้หลายโค้ด คั่นด้วยเว้นวรรคหรือขึ้นบรรทัดใหม่

สั่งการยังไม่ได้เช็กการเข้าสู่ระบบ

หน้าเข้าสู่ระบบของ Garena ปฏิเสธเบราว์เซอร์ที่เครื่องมือควบคุม ("Access is temporarily restricted") — เครื่องมือนี้จึงไม่เปิดหน้า Garena เอง: มันหาโค้ด จัดคิว และจำผล ส่วนการแลกคุณทำในเบราว์เซอร์ปกติ

บันทึกการทำงานยังไม่ได้สั่งงาน
