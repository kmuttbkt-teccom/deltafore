# deltafore — Garena Delta Force

สองอย่างในโฟลเดอร์นี้

1. **ศูนย์โค้ด** (`redeem/` + `web/`) — หาโค้ดแลกของจากหน้าเว็บรวมโค้ดทั่วโลก จัดคิว จำว่าโค้ดไหนแลกแล้ว/หมดอายุ/ผิด — **การแลกคุณทำเองในเบราว์เซอร์ปกติ** ที่[หน้าแลกโค้ดทางการของ Garena](https://redeem.df.garena.sg/th/cdkgarena.html)
2. **คู่มือสายแข่ง** ([PRO-GUIDE.md](PRO-GUIDE.md)) — การตั้งค่า เมต้า แรงก์ รายการแข่ง ช่องถ่ายทอดสด แผนฝึก

ต้องมี Node.js 22 ขึ้นไป — **ไม่ต้อง `npm install` อะไรเลย**

> **ทำไมไม่แลกให้อัตโนมัติ** — 9 ต.ค. 2026 หน้าเข้าสู่ระบบของ Garena (`auth.garena.com`) ตอบเบราว์เซอร์ที่เครื่องมือนี้เปิดว่า *"Access is temporarily restricted … Automated (bot) activity … Use of developer or inspection tools"* ระบบกันบอตของ Garena จับได้ว่าเบราว์เซอร์ถูกเครื่องมือควบคุม เครื่องมือนี้ **จะไม่พยายามเลี่ยงการตรวจจับนั้น** (เสี่ยงต่อบัญชีและผิดเจตนาของ Garena ชัดเจน) จึงเปลี่ยนเป็น "โหมดแลกเอง": เครื่องมือทำงานหาโค้ดและจดผล ส่วนที่แตะหน้า Garena เป็นมือคุณ

---

## ใช้งาน

```bash
npm run web
```

แล้วเปิด <http://localhost:4310> **ในเบราว์เซอร์ปกติของคุณ** (ตัวที่คุณเข้าสู่ระบบ Garena ได้ตามปกติ)

1. กด **ตรวจหน้าเว็บรวมโค้ดทั่วโลก** — โค้ดที่พบเข้ารายการเป็น "รออนุมัติ"
2. กด **อนุมัติ** โค้ดที่อยากลอง (หรือวางโค้ดที่ได้จากไลฟ์/เพจลงช่อง "เพิ่มโค้ด")
3. ใช้ **ตัวช่วยกรอกอัตโนมัติ** (หัวข้อถัดไป) — หรือทำเอง: **คัดลอกโค้ด** → **เปิดหน้าแลกโค้ด** → วาง → กด "ไปแลก" แล้วกลับมากดปุ่มผลที่ตรงกับข้อความที่หน้า Garena ตอบ

ปุ่มผล (สำเร็จ / เคยแลกแล้ว / หมดอายุ / โค้ดไม่ถูกต้อง / ถูกแลกครบแล้ว / ข้าม) **แค่จดผล ไม่ได้ส่งโค้ด** — จดผิดกด "เข้าคิวใหม่" ที่แถวนั้นในรายการ

### ตัวช่วยกรอกอัตโนมัติ — ทุกขั้นตอนอัตโนมัติ (หรือเลือกกดยืนยันเองได้)

ระบบใส่โค้ดลงช่องของหน้าแลกให้ **กดยืนยันแลกโค้ดให้อัตโนมัติ** (หน่วงเวลาสั้น ๆ ~1.2 วินาทีให้เป็นธรรมชาติ) อ่านคำตอบของหน้า จดผล พักตามจังหวะที่ตั้ง (5 วินาที – 1 นาที) แล้วใส่โค้ดถัดไป วนจนหมดคิว **คุณไม่ต้องกดอะไรเลยระหว่างแลก**

1. **ติดตั้งบุ๊กมาร์ก "DF ช่วยกรอก"**
   - **คอมพิวเตอร์:** ลากปุ่ม "DF ช่วยกรอก" ไปวางบนแถบบุ๊กมาร์ก (ทำครั้งเดียว · ไม่เห็นแถบ กด Ctrl+Shift+B)
   - **มือถือ / ไอแพด / แท็บเล็ต:** กด "คัดลอกโค้ดบุ๊กมาร์ก" แล้วดูวิธีตั้งในหัวข้อ "ใช้บนมือถือ / ไอแพด / แท็บเล็ต"
2. **กด "เปิดหน้าแลกโค้ด"** ในแผงตัวช่วย (เปิดจากปุ่มนี้ สองหน้าต่างคุยกันได้ · เข้าสู่ระบบ Garena ในหน้านั้น)
3. **ในหน้าแลกโค้ด กดบุ๊กมาร์ก "DF ช่วยกรอก"** — แถบสีทองขึ้นด้านบน = เชื่อมกันแล้ว
4. ระบบใส่โค้ด → **กดยืนยันอัตโนมัติ** → จดผล → พักนับถอยหลัง → ไปโค้ดถัดไป วนจนหมดคิว!

* **โหมดอัตโนมัติ / กดยืนยันเอง:** บนแถบสีทองมีตัวเลือก `[✓] กดแลกอัตโนมัติ` ติ๊กออกได้ตลอดเวลาถ้าต้องการกดยืนยันด้วยมือทีละโค้ด
* **ปุ่มพักชั่วคราว:** มีปุ่ม `[ พักชั่วคราว ]` บนแถบสีทอง กดหยุดหรือทำต่อได้ทุกเมื่อ
* **ความปลอดภัย:** ตัวช่วยรันในเบราว์เซอร์ปกติของคุณ (ไม่ใช่เครื่องมืออัตโนมัติประเภท Puppeteer/Selenium ที่โดนตรวจจับ) และมีจังหวะหน่วงเวลาเหมือนมนุษย์ใช้งาน
* คำตอบที่ตัวช่วยไม่รู้จัก (ข้อความใหม่ เครือข่ายขัดข้อง หรือมีปัญหา) จะหยุดรอให้คุณเลือกผลเอง หรือกด "ใส่โค้ดนี้อีกครั้ง" / "ข้าม"
* โค้ดที่ "ยังไม่ถึงเวลาแลก" อยู่ในคิวต่อ แต่ไม่ถูกเสนอซ้ำในรอบนั่งเดียวกัน
* ลองก่อนได้ในโหมดสาธิต (`npm run demo`) กับหน้าแลกโค้ดจำลอง

คิวเรียงให้: โค้ดที่คุณวางเอง → โค้ดจากหน้าของเซิร์ฟ Garena → โค้ดจากหน้าของเซิร์ฟ Global (ซึ่งหน้า Garena มักตอบว่าไม่ถูกต้อง) · ในกลุ่มเดียวกัน โค้ดที่พบหลายแหล่งมาก่อน · อยากแลกตัวไหนก่อนกด "แลกตัวนี้" ที่แถวนั้น

| แท็บ | มีอะไร |
|---|---|
| **แลกโค้ด** | แผงแลกเอง · เพิ่มโค้ด · ตรวจหน้าเว็บ + สวิตช์ "ตรวจหาโค้ดใหม่อัตโนมัติ" · บันทึกการทำงาน · รายการโค้ดพร้อมผล |
| **งานแข่ง & ถ่ายทอดสด** | ช่องทางการทั้งหมด · รายการที่กำลังแข่ง/กำลังจะมาพร้อมนับถอยหลัง · รายการที่จบแล้วพร้อมผล (แก้ได้ใน `events.json`) |
| **คู่มือสายแข่ง** | `PRO-GUIDE.md` พร้อมสารบัญ |

* เว็บฟังเฉพาะเครื่องนี้ (`127.0.0.1`) และไม่รับคำสั่งจากหน้าเว็บอื่นที่เปิดอยู่ในเบราว์เซอร์เดียวกัน
* "ตรวจหาโค้ดใหม่อัตโนมัติ" ทำงานเฉพาะตอนที่เซิร์ฟเวอร์นี้เปิดอยู่ และทำแค่ดึงหน้าเว็บรวมโค้ด — ไม่เปิดหน้า Garena
* **โหมดสาธิต** — `npm run demo` แล้วเปิด <http://localhost:4311>: หน้าแลกโค้ดจำลองและโค้ดตัวอย่างในโฟลเดอร์ชั่วคราว ไม่มีอะไรไปถึง Garena และไม่แตะ `data/`

## คำสั่งในเทอร์มินัล (ทำได้เท่ากับหน้าเว็บ)

## หาโค้ดจากทั่วโลก (`scan`)

ดึงหน้าเว็บรวมโค้ด 10 แห่งพร้อมกัน แล้วแยกสิ่งที่เป็นโค้ดออกมา

| กลุ่ม | แหล่ง | ใช้กับบัญชี Garena ไทยได้ไหม |
|---|---|---|
| Garena SEA / VN / TW | joytify, gearvn, dienthoaivui, hoanghamobile, bluestacks (VN), ldshop (TW) | หน้าแลกเดียวกัน (`redeem.df.garena.sg`) — แต่บางโค้ดจำกัดประเทศ |
| Global | timesaver.gg, pockettactics, lootbar, mobilematters | **ส่วนใหญ่ไม่ได้** — เป็นโค้ดของ `playdeltaforce.com` (Steam/Global) ซึ่งหน้า Garena จะตอบว่า "โค้ดไม่ถูกต้อง" |

* อ่านได้ทั้งโค้ดตัวพิมพ์ใหญ่ล้วนและตัวพิมพ์ผสม (`DFWizard309`) ในหน้าภาษาอังกฤษ ไทย เวียดนาม อินโดนีเซีย สเปน โปรตุเกส จีนตัวเต็ม
* ตัดส่วนที่หน้าเว็บระบุเองว่า **หมดอายุ** ออก (หัวข้อ แถวตาราง หรือรายการที่เขียนว่า expired / hết hạn / 過期 ฯลฯ) — แต่หลายหน้าไม่ได้แยกไว้ โค้ดเก่าจึงยังติดมา
* แต่ละโค้ดจำไว้ว่าเจอในกี่แหล่ง — เจอหลายแหล่งไม่ได้แปลว่ายังใช้ได้ แค่แปลว่ามีจริง
* **ไม่มีทางรู้ว่าโค้ดยังใช้ได้โดยไม่ลองแลกกับบัญชีจริง**
* เว็บที่ปิดไม่ให้เครื่องมืออ่าน (ตอบ 403) ถูกข้าม: dienmayxanh, fptshop, phucanh, dcard, gamsgo ส่วน Facebook / Discord / TikTok อ่านไม่ได้เลย — โค้ดจากไลฟ์แข่งและเพจต้องวางเอง
* การดึงหน้าเว็บบอกตัวตนตรง ๆ (`deltafore-code-watcher`) หนึ่งคำขอต่อหน้าต่อรอบ และไม่แตะเว็บของ Garena

## โหมดอัตโนมัติ (ปิดอยู่ และไม่แนะนำ)

โค้ดส่วนที่ให้เครื่องมือเปิดเบราว์เซอร์ พิมพ์โค้ด และกดแลกเองยังอยู่ (`redeem/portal.js`, `redeem/cdp.js`) และผ่านการทดสอบกับหน้าจำลอง แต่ **ใช้กับ Garena จริงไม่ได้**: ขั้นเข้าสู่ระบบถูกปฏิเสธตามที่เล่าไว้ข้างบน

* เปิดได้ด้วย `"mode": "auto"` ใน `config.json` — คำสั่ง `login` `run` `now` `status` `logout` และปุ่มที่ตรงกันในหน้าเว็บจะกลับมา
* ถ้าเปิดแล้วเจอหน้า "Access is temporarily restricted" อีก เครื่องมือจะหยุดเองและบอก — **อย่ากดซ้ำ** การถูกจับซ้ำ ๆ อาจทำให้การจำกัดบนเครือข่าย/บัญชีของคุณนานขึ้น
* จะไม่มีการเพิ่มอะไรเพื่อซ่อนเครื่องมือจากระบบกันบอต

## ตั้งค่า (`config.json`)

| ช่อง | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `mode` | `manual` | `manual` = แลกเอง · `auto` = ดูหัวข้อข้างบน |
| `portal` | หน้าแลกโค้ดภาษาไทย | ลิงก์ของปุ่ม "เปิดหน้าแลกโค้ด" — เปลี่ยน `/th/` เป็น `/en/` ได้ |
| `watchEveryMin` | `120` | รอบของ `watch` |
| `maxInvalidPerDay` | `5` | หน้าเว็บแสดงจำนวนโค้ดผิดของวันนี้เทียบกับเลขนี้ (โหมด auto: หยุดเมื่อถึง) |
| `sources` | 10 แหล่ง (Garena 6 · Global 4) | `{ name, url, auto, enabled, match }` — `"enabled": false` ปิดแหล่งนั้น · `match` เป็น regex เช่น `"^GARENA"` · ชื่อที่ขึ้นต้นด้วย `Garena` ถูกจัดไว้หน้าคิว |
| `browser` `headless` `delayBetweenCodesSec` `maxCodesPerRun` `maxTriesPerCode` `loginWaitMin` `keepLoginDays` `rejectOptionalCookies` | | ใช้เฉพาะโหมด auto |

## ไฟล์

```
redeem/index.js    คำสั่งทั้งหมด
redeem/sources.js  ดึงหน้าเว็บที่เฝ้า แยกสิ่งที่หน้าตาเป็นโค้ด ตัดส่วนที่หมดอายุ
redeem/store.js    data/codes.json · data/redeem.log · config · ลำดับคิว
redeem/portal.js   (โหมด auto) หน้าแลกโค้ด: อ่านสถานะ กรอก กด อ่านคำตอบ
redeem/cdp.js      (โหมด auto) เปิดและคุมเบราว์เซอร์
web/server.js      เว็บศูนย์บัญชาการ (http บน 127.0.0.1, ไม่ใช้แพ็กเกจ)
web/public/        หน้าเว็บ: index.html · style.css · app.js
events.json        รายการแข่งที่แท็บ "งานแข่ง" แสดง
web/public/fill-helper.js   ตัวช่วยกรอก (บุ๊กมาร์ก) ที่ทำงานในหน้าแลกโค้ด
test/              หน้าแลกโค้ดจำลอง + ชุดทดสอบ (npm test — run.js 53 ข้อ · helper-e2e.js 23 ข้อ)
data/              รายการโค้ด บันทึก — อยู่ในเครื่องนี้เท่านั้น
```
