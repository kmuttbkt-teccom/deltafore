# deltafore — Garena Delta Force · RoV

สองอย่างในโฟลเดอร์นี้ สำหรับสองเกม (สลับเกมได้ที่มุมบนของหน้าเว็บ)

1. **ศูนย์โค้ด** (`redeem/` + `web/`) — หาโค้ดแลกของจากหน้าเว็บรวมโค้ด จัดคิว จำว่าโค้ดไหนแลกแล้ว/หมดอายุ/ผิด
   - **Delta Force:** แลกในเบราว์เซอร์ปกติของคุณที่[หน้าแลกโค้ดทางการของ Garena](https://redeem.df.garena.sg/th/cdkgarena.html) — มีตัวช่วยกรอก
   - **RoV:** โค้ดกรอกในตัวเกม — ศูนย์โค้ดหา จัดคิว ให้คัดลอกไปวางในเกม แล้วจดผล
2. **คู่มือสายแข่ง** ([PRO-GUIDE.md](PRO-GUIDE.md) · [ROV-GUIDE.md](ROV-GUIDE.md)) — การตั้งค่า แรงก์ รายการแข่ง ช่องถ่ายทอดสด แผนฝึก

ต้องมี Node.js 22 ขึ้นไป — **ไม่ต้อง `npm install` อะไรเลย**

> **เรื่องระบบกันบอตของ Garena — อ่านก่อนใช้** — 9 ต.ค. 2026 หน้าเข้าสู่ระบบของ Garena (`auth.garena.com`) ตอบเบราว์เซอร์ที่เครื่องมือนี้เปิดและควบคุมเองว่า *"Access is temporarily restricted … Automated (bot) activity … Use of developer or inspection tools"* โหมดที่เครื่องมือขับเบราว์เซอร์เอง (`"mode": "auto"`) จึงปิดไว้
>
> ตัวช่วยกรอก (บุ๊กมาร์ก) ทำงานในเบราว์เซอร์ปกติของคุณหลังคุณเข้าสู่ระบบเอง และมีตัวเลือก **"กดยืนยันอัตโนมัติ"** ซึ่งให้สคริปต์กดปุ่มแลกแทนคุณ ตัวเลือกนี้คือการใช้บอตกับบริการที่เพิ่งปฏิเสธบอต: การที่ยังไม่ถูกจับไม่ได้แปลว่าได้รับอนุญาต ข้อตกลงของ Garena อาจถือว่าผิด และผลที่ตามมา (จำกัดการใช้งาน/ระงับบัญชี) ตกกับบัญชีของคุณ — **เอาติ๊กออกแล้วกดยืนยันเองทีละโค้ดได้เสมอ** ซึ่งเป็นวิธีที่ไม่มีคำขอใดไปถึง Garena โดยไม่ผ่านมือคุณ

## ใช้งาน

```bash
npm run web
```

แล้วเปิด <http://localhost:4310> **ในเบราว์เซอร์ปกติของคุณ** (ตัวที่คุณเข้าสู่ระบบ Garena ได้ตามปกติ)

1. กด **ตรวจหน้าเว็บรวมโค้ดทั่วโลก** — โค้ดที่พบเข้ารายการเป็น "รออนุมัติ"
2. กด **อนุมัติ** โค้ดที่อยากลอง (หรือวางโค้ดที่ได้จากไลฟ์/เพจลงช่อง "เพิ่มโค้ด")
3. ใช้ **ตัวช่วยกรอกอัตโนมัติ** (หัวข้อถัดไป) — หรือทำเอง: **คัดลอกโค้ด** → **เปิดหน้าแลกโค้ด** → วาง → กด "ไปแลก" แล้วกลับมากดปุ่มผลที่ตรงกับข้อความที่หน้า Garena ตอบ

ปุ่มผล (สำเร็จ / เคยแลกแล้ว / หมดอายุ / โค้ดไม่ถูกต้อง / ถูกแลกครบแล้ว / ข้าม) **แค่จดผล ไม่ได้ส่งโค้ด** — จดผิดกด "เข้าคิวใหม่" ที่แถวนั้นในรายการ

### ตัวช่วยกรอกอัตโนมัติ — ทุกขั้นตอนอัตโนมัติ (หรือเลือกกดยืนยันเองได้)

ระบบใส่โค้ดลงช่องของหน้าแลกให้ **กดยืนยันแลกโค้ดให้อัตโนมัติ** (หน่วงเวลาสั้น ๆ ~1.2 วินาทีให้เป็นธรรมชาติ) อ่านคำตอบของหน้า จดผล พักตามจังหวะที่ตั้ง (5 วินาที – 1 นาที) แล้วใส่โค้ดถัดไป วนจนหมดคิว **คุณไม่ต้องกดอะไรเลยระหว่างแลก**

1. **ติดตั้งบุ๊กมาร์ก "DF ช่วยกรอก"**
   - **คอมพิวเตอร์:** ลากปุ่ม "DF ช่วยกรอก" ไปวางบนแถบบุ๊กมาร์ก (ทำครั้งเดียว · ไม่เห็นแถบ กด Ctrl+Shift+B)
   - **มือถือ / ไอแพด / แท็บเล็ต:** กด "คัดลอกโค้ดบุ๊กมาร์ก" แล้วดูวิธีตั้งในหัวข้อ "ใช้บนมือถือ / ไอแพด / แท็บเล็ต"
2. **กด "เปิดหน้าแลกโค้ด"** ในแผงตัวช่วย (เปิดจากปุ่มนี้ สองหน้าต่างคุยกันได้ · เข้าสู่ระบบ Garena ในหน้านั้น)
3. **ในหน้าแลกโค้ด กดบุ๊กมาร์ก "DF ช่วยกรอก"** — แถบสีทองขึ้นด้านบน = เชื่อมกันแล้ว
4. ระบบใส่โค้ด → **กดยืนยันอัตโนมัติ** → จดผล → พักนับถอยหลัง → ไปโค้ดถัดไป วนจนหมดคิว!

* **โหมดอัตโนมัติ / กดยืนยันเอง:** บนแถบสีทองมีตัวเลือก `[✓] กดแลกอัตโนมัติ` ติ๊กออกได้ตลอดเวลาถ้าต้องการกดยืนยันด้วยมือทีละโค้ด
* **ปุ่มพักชั่วคราว:** มีปุ่ม `[ พักชั่วคราว ]` บนแถบสีทอง กดหยุดหรือทำต่อได้ทุกเมื่อ
* **ความเสี่ยง:** ตัวช่วยรันในเบราว์เซอร์ปกติของคุณ แต่เมื่อเปิด "กดแลกอัตโนมัติ" มันคือสคริปต์ที่ส่งโค้ดแทนคุณ — ไม่มีอะไรรับประกันว่า Garena จะไม่ตรวจพบหรือไม่ถือว่าผิดข้อตกลง ความเสี่ยงอยู่กับบัญชีของผู้ใช้เอง (ดูหมายเหตุที่หัวไฟล์)
* คำตอบที่ตัวช่วยไม่รู้จัก (ข้อความใหม่ เครือข่ายขัดข้อง หรือมีปัญหา) จะหยุดรอให้คุณเลือกผลเอง หรือกด "ใส่โค้ดนี้อีกครั้ง" / "ข้าม"
* โค้ดที่ "ยังไม่ถึงเวลาแลก" อยู่ในคิวต่อ แต่ไม่ถูกเสนอซ้ำในรอบนั่งเดียวกัน
* ลองก่อนได้ในโหมดสาธิต (`npm run demo`) กับหน้าแลกโค้ดจำลอง

คิวเรียงให้: โค้ดที่คุณวางเอง → โค้ดจากหน้าของเซิร์ฟ Garena → โค้ดจากหน้าของเซิร์ฟ Global (ซึ่งหน้า Garena มักตอบว่าไม่ถูกต้อง) · ในกลุ่มเดียวกัน โค้ดที่พบหลายแหล่งมาก่อน · อยากแลกตัวไหนก่อนกด "แลกตัวนี้" ที่แถวนั้น

| แท็บ | มีอะไร |
|---|---|
| **แลกโค้ด** | แผงแลกเอง · เพิ่มโค้ด · ตรวจหน้าเว็บ + สวิตช์ "ตรวจหาโค้ดใหม่อัตโนมัติ" · บันทึกการทำงาน · รายการโค้ดพร้อมผล |
| **งานแข่ง & ถ่ายทอดสด** | ช่องทางการทั้งหมด · รายการที่กำลังแข่ง/กำลังจะมาพร้อมนับถอยหลัง · รายการที่จบแล้วพร้อมผล (แก้ได้ใน `events.json`) |
| **คู่มือสายแข่ง** | `PRO-GUIDE.md` พร้อมสารบัญ |

* เว็บฟังเฉพาะเครื่องนี้ (`127.0.0.1`) และไม่รับคำสั่งจากหน้าเว็บอื่นที่เปิดอยู่ในเบราว์เซอร์เดียวกัน
* "ตรวจหาโค้ดใหม่อัตโนมัติ" ทำงานเฉพาะตอนที่เซิร์ฟเวอร์นี้เปิดอยู่ และทำแค่ดึงหน้าเว็บรวมโค้ด — ไม่เปิดหน้า Garena
* **โหมดสาธิต** — `npm run demo` แล้วเปิด <http://localhost:4311>: หน้าแลกโค้ดจำลองและโค้ดตัวอย่างในโฟลเดอร์ชั่วคราว ไม่มีอะไรไปถึง Garena และไม่แตะ `data/`

## ใช้บนมือถือ / ไอแพด / แท็บเล็ต

เปิดเซิร์ฟเวอร์แบบให้เครื่องอื่นใน Wi-Fi เดียวกันเข้าได้:

```bash
npm run web:lan
```

* หน้าเว็บบนคอม (หัวข้อ "ใช้บนมือถือ / ไอแพด / แท็บเล็ต" ในแผงตัวช่วย) จะแสดง **ลิงก์ที่มีรหัส 10 ตัว** — เปิดลิงก์นั้นบนมือถือ ครั้งเดียวพอ เครื่องจะจำไว้ · ไม่มีรหัสเข้าไม่ได้ และ `npm run web` ธรรมดาไม่เปิดให้เครื่องอื่นเข้าเลย
* ครั้งแรก Windows จะถามว่าให้ Node.js รับการเชื่อมต่อจากเครือข่ายส่วนตัวไหม — ต้องกดอนุญาต
* **RoV บนมือถือ** (ทางที่สะดวกที่สุด): เลือกเกม RoV → "คัดลอกโค้ด" → สลับไปวางในเกม → กลับมากดผล
* **Delta Force บนมือถือ**: ติดตั้งบุ๊กมาร์กตัวช่วยตามขั้นตอนในหน้าเว็บ (iPhone/iPad: แก้ที่อยู่ของบุ๊กมาร์ก · Android Chrome: พิมพ์ชื่อบุ๊กมาร์กในแถบที่อยู่แล้วแตะรายการ) ตัวช่วยถือคิวไว้เองในแท็บหน้าแลกโค้ด เสร็จแล้วกด **"กลับศูนย์โค้ด"** ผลทั้งหมดถูกส่งกลับมาจด
* ยังไม่ได้ลองบนมือถือ/ไอแพดเครื่องจริง — ลองแล้วเฉพาะการจำลองขนาดจอ (375 และ 768 พิกเซล) กับการเข้าผ่านที่อยู่เครือข่ายด้วยรหัส

## หลายเกม

| เกม | แลกโค้ดที่ | แหล่งโค้ด | ข้อมูล |
|---|---|---|---|
| Delta Force | หน้าเว็บของ Garena (มีตัวช่วยกรอก) | 10 หน้า (Garena 6 · Global 4) | `data/codes.json` |
| RoV | ในตัวเกม: หน้ากิจกรรม/ประกาศ → ช่องกรอกโค้ด | 4 หน้าภาษาไทย (sanook ×2, memuplay, bluestacks) | `data/codes-rov.json` |

* ในเทอร์มินัลใส่ `--game rov` หน้าคำสั่ง: `node redeem --game rov scan` · `node redeem --game rov next`
* โค้ด RoV จำนวนมากเป็นคำตัวพิมพ์ใหญ่ล้วน (`SEAMONSTER`) — ตัวอ่านหน้าเว็บรับรูปแบบนี้เฉพาะเกมที่ตั้ง `"words": true`
* เพิ่มเกมอื่น: เพิ่มรายการใน `config.json` ช่อง `games` (`name`, `redeem`: `ingame`/`web`, `how`, `sources`) — รายการแข่งใส่ `"game": "<ชื่อ>"` ใน `events.json` · คู่มือชื่อ `<ชื่อตัวพิมพ์ใหญ่>-GUIDE.md`

## โค้ดแต่งปืน (แท็บ 04 — Delta Force)

ชุดแต่งปืนที่ผู้เล่นแจกไว้เป็น "รหัสแชร์" หนึ่งบรรทัด เช่น `CI-19 Assault Rifle-Warfare-6HLOANO09MFFCME3G7LT2` (ชื่อปืน-โหมด-โค้ด) — ไม่ใช่โค้ดแลกของ ไม่มีอะไรถูกส่งไปที่ไหน แค่คัดลอกไปวางในเกม

* **ใช้:** กด **คัดลอก** ที่การ์ด → ในเกม: หน้าแต่งปืน → ชุดแต่ง (Loadout) → **นำเข้า (Import)** → วางทั้งบรรทัด *รวมชื่อปืน*
* **หา:** ปุ่ม "ตรวจหาโค้ดแต่งปืนใหม่" (หรือ `node redeem builds scan`) อ่านจาก 5 เว็บ: codmunity, deltaforcetools, deltaforcedb, skycoach, buffbuff — แก้รายชื่อได้ที่ `config.json` ช่อง `buildSources`
* **รูป:** การ์ดแสดง **ภาพปืนในเกม** ของ 38 จาก 54 รุ่น — ไม่ได้คัดลอกไฟล์ภาพมาไว้ที่นี่: เก็บเฉพาะ *ที่อยู่* ของภาพในหน้ารายการอาวุธของ deltaforcedb.com (`config.json` ช่อง `gamePictures`) แล้วให้เบราว์เซอร์แสดงจากเว็บนั้นโดยตรง พร้อมชื่อเว็บและลิงก์ใต้ภาพ · ภาพเป็นลิขสิทธิ์ของผู้พัฒนาเกม ถ้าเว็บต้นทางปิดหรือเลิกให้แสดง การ์ดจะกลับไปใช้ภาพเงาเอง · ปิดได้ด้วย `"enabled": false` แล้วสั่ง `node redeem builds images`
* รุ่นที่ยังไม่มีภาพในเกม (S12K, PSG-1, VSS, M14, M1014, MK47, SKS, SR9, Double-Barrel) แสดง **ภาพปืนจริงที่เป็นต้นแบบ** จาก Wikipedia / Wikimedia Commons (ภาพลิขสิทธิ์เสรี จับคู่ที่ `weapons.json`) · ที่ไม่มีทั้งสองอย่าง (K437, KC-17, LT, MK4, QCQ171, QJB201) แสดงภาพเงาตามประเภทปืน
* **กรอง:** โหมด (Warfare / Operations — ใช้ข้ามกันไม่ได้) · ประเภทปืน · ค้นหาชื่อ · ⭐ เก็บที่ชอบ · ซ่อนที่ไม่ใช้
* **เพิ่มเอง:** วางบรรทัดที่ได้จากปุ่มแชร์ในเกมหรือจากคลิป (รับชื่อปืน/โหมดภาษาไทยด้วย) — หรือ `node redeem builds add "<บรรทัด>"`
* **แต่งอะไรบ้าง:** การ์ดบอกสไตล์ จำนวนชิ้น และ (เท่าที่หน้าต้นทางให้) รายการของแต่งทีละช่อง พร้อมลิงก์ไปหน้าต้นทาง — ตอนนี้ 11 จาก 77 ชุดมีรายการครบ ที่เหลือมีสไตล์/จำนวนชิ้น/ลิงก์
* **ข้อจำกัด:** Garena ระบุในคู่มือ Operations ว่า "โค้ดของ Garena ใช้ได้เฉพาะเวอร์ชัน Garena" — เว็บต้นทางเป็นของเซิร์ฟ Global/PC โค้ดจึง **อาจนำเข้าไม่ได้** ให้ลองหนึ่งชุดก่อน ถ้าไม่ได้ให้ประกอบตาม "แต่งอะไรบ้าง" · แพตช์สมดุลปืนทำให้ชุดแต่งเก่าด้อยลงหรือนำเข้าไม่ได้ · เว็บต้นทางไม่ได้บอกวันที่ของแต่ละชุด
* เก็บที่ `data/builds.json`

## แผนที่ & จุดของ (แท็บ 05 — Delta Force)

เลือกแผนที่ → เห็น **แผนที่แบบโต้ตอบพร้อมหมุดของทุกประเภท** (ตู้เซฟ ห้องคีย์การ์ด กล่องลับ ของแดง จุดเกิด ทางออก ฯลฯ) ในกรอบ, ตัวเลขสรุปของแผนที่นั้น, รายชื่อห้องคีย์การ์ด, และบันทึกภาษาไทย

* **Tide Prison** ยังไม่พบแผนที่แบบโต้ตอบ — มีแต่บันทึกและลิงก์คู่มือ
* `maps.json` — รายชื่อแผนที่ ที่อยู่ของแผนที่โต้ตอบ และจำนวนหมุดแต่ละประเภทที่นับจากแผนที่ของ deltaforcetools.gg ณ วันที่ในช่อง `asOf` (ข้อมูลจากผู้เล่น ไม่ใช่ของทางเกม · สองเว็บนับได้ไม่เท่ากัน) — **แก้ด้วยมือเมื่อซีซันเปลี่ยนแผนที่** ไม่มีตัวดึงอัตโนมัติ
* `DF-MAPS.md` — บันทึกของแต่ละแผนที่ (หัวข้อ `## …` ที่มีชื่อแผนที่) และหลักทั่วไป

## ของฉัน (แท็บ 07 — Delta Force)

ของส่วนตัวของผู้เล่น **เก็บในเบราว์เซอร์ของเครื่องนั้นเท่านั้น** (ไม่ขึ้นเซิร์ฟเวอร์ ไม่เข้าที่เก็บโค้ด — ล้างข้อมูลเบราว์เซอร์แล้วหาย):

* **เช็กลิสต์** — รายวัน / รายสัปดาห์ / ทำครั้งเดียวก่อนปิด จาก `checklist.json` (แก้ได้ อย่าเปลี่ยน `id`) · ติ๊กของรายวันและรายสัปดาห์กลับมาว่างเองเมื่อข้ามรอบ · รายการที่มี `until` หายไปเองหลังวันปิด · เพิ่มรายการของตัวเองได้ในหน้า · **เวลารีเซ็ตของเกมยังไม่ยืนยัน** ค่าเริ่มต้นคือ 00:00 และวันจันทร์ ให้ตั้งในหน้าให้ตรงกับตัวนับถอยหลังในเกม
* **ป้ายบนหัวเว็บ** — "วันนี้ 2/4" และ "ใกล้ปิด เหลือ N วัน" (ของที่ต้องทำครั้งเดียวและยังไม่ติ๊ก ที่ปิดเร็วที่สุด)
* **สมุดตกปลา** — ปลา 27 ชนิดจาก `fish.json` ติ๊กตัวที่จับได้ บอกว่าใช้คันทุ่นหรือคันเหยื่อปลอม · ใส่เลเวลตกปลาแล้วบอกด่านสอบถัดไปว่าต้องส่งปลาอะไร — ข้อมูลจากคู่มือของผู้เล่น (ด่านเลเวล 30 และ 40 ยังไม่ยืนยัน)
* **ย้ายข้อมูล** — "สร้างไฟล์ย้ายข้อมูล" รวมผลของโค้ด ดาวของชุดแต่ง ชุดแต่งที่ลองแล้ว สมุดปลา โน้ตแผนที่ และเช็กลิสต์เป็นไฟล์เดียว (ไม่มีรหัสผ่านหรือข้อมูลบัญชี) · อีกเครื่องวางข้อความหรือเลือกไฟล์ → "ตรวจดูก่อน" → "นำเข้า" · **ไม่ลบของในเครื่องปลายทาง:** ผลโค้ดบันทึกเฉพาะตัวที่เครื่องนั้นยังไม่มีผล ดาวมีแต่เพิ่ม โน้ตของสองเครื่องเก็บไว้ทั้งคู่ · ใช้ได้ทั้งคอม (มีเซิร์ฟเวอร์) และเว็บ github.io
* ในแท็บ 04 แต่ละการ์ดมีปุ่ม **"✓ นำเข้าได้ / ✗ ไม่ได้"** — ลองโค้ดในเกมแล้วกดไว้ ชุดที่นำเข้าไม่ได้จะจางและไปอยู่ท้ายรายการ มีตัวกรองของแต่ละแบบ
* ในแท็บ 05 ใต้แผนที่มีช่อง **"โน้ตของฉัน"** ของแต่ละแผนที่ และปุ่มลัดไปหน้า **รหัสประตูประจำวัน** ของ deltaforcetools.gg — ⚠️ หน้านั้นไม่บอกว่าใช้กับเซิร์ฟ Garena ได้ ไม่อ้างแหล่งทางการ และโปรโมตบริการเติมเกม ยังไม่ได้ตรวจว่ารหัสถูก

## หาโค้ดจากทั่วโลก (`scan`)

ดึงหน้าเว็บรวมโค้ด 10 แห่งพร้อมกัน แล้วแยกสิ่งที่เป็นโค้ดออกมา

| กลุ่ม | แหล่ง | ใช้กับบัญชี Garena ไทยได้ไหม |
|---|---|---|
| Garena SEA / VN / TW | joytify, gearvn, dienthoaivui, hoanghamobile, bluestacks (VN), ldshop (TW) | หน้าแลกเดียวกัน (`redeem.df.garena.sg`) — แต่บางโค้ดจำกัดประเทศ |
| Global | timesaver.gg, pockettactics, lootbar, mobilematters | **ส่วนใหญ่ไม่ได้** — เป็นโค้ดของ `playdeltaforce.com` (Steam/Global) ซึ่งหน้า Garena จะตอบว่า "โค้ดไม่ถูกต้อง" |

* อ่านได้ทั้งโค้ดตัวพิมพ์ใหญ่ล้วนและตัวพิมพ์ผสม (`DFWizard309`) ในหน้าภาษาอังกฤษ ไทย เวียดนาม อินโดนีเซีย สเปน โปรตุเกส จีนตัวเต็ม
* ตัดส่วนที่หน้าเว็บระบุเองว่า **หมดอายุ** ออก (หัวข้อ แถวตาราง หรือรายการที่เขียนว่า expired / hết hạn / 過期 ฯลฯ) — แต่หลายหน้าไม่ได้แยกไว้ โค้ดเก่าจึงยังติดมา
* แต่ละโค้ดจำไว้ว่าเจอในกี่แหล่ง — เจอหลายแหล่งไม่ได้แปลว่ายังใช้ได้ แค่แปลว่ามีจริง
* **ไม่มีทางรู้ว่าโค้ดยังใช้ได้โดยไม่ลองแลกกับบัญชีจริง**
* เว็บที่ปิดไม่ให้เครื่องมืออ่าน (ตอบ 403) ถูกข้าม: dienmayxanh, fptshop, phucanh, dcard, gamsgo ส่วน Facebook / Discord / TikTok อ่านไม่ได้เลย — โค้ดจากไลฟ์แข่งและเพจต้องวางเอง
* การดึงหน้าเว็บบอกตัวตนตรง ๆ (`deltafore-code-watcher`) หนึ่งคำขอต่อหน้าต่อรอบ และไม่แตะเว็บของ Garena

## โหมดอัตโนมัติ (ปิดอยู่ และไม่แนะนำ)

โค้ดส่วนที่ให้เครื่องมือเปิดเบราว์เซอร์ พิมพ์โค้ด และกดแลกเองยังอยู่ (`redeem/portal.js`, `redeem/cdp.js`) และผ่านการทดสอบกับหน้าจำลอง แต่ **ใช้กับ Garena จริงไม่ได้**: ขั้นเข้าสู่ระบบถูกปฏิเสธตามที่เล่าไว้ข้างบน

* เปิดได้ด้วย `"mode": "auto"` ใน `config.json` — คำสั่ง `login` `run` `now` `status` `logout` และปุ่มที่ตรงกันในหน้าเว็บจะกลับมา
* ถ้าเปิดแล้วเจอหน้า "Access is temporarily restricted" อีก เครื่องมือจะหยุดเองและบอก — **อย่ากดซ้ำ** การถูกจับซ้ำ ๆ อาจทำให้การจำกัดบนเครือข่าย/บัญชีของคุณนานขึ้น
* จะไม่มีการเพิ่มอะไรเพื่อซ่อนเครื่องมือจากระบบกันบอต

## ตั้งค่า (`config.json`)

| ช่อง | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `mode` | `manual` | `manual` = แลกเอง · `auto` = ดูหัวข้อข้างบน |
| `portal` | หน้าแลกโค้ดภาษาไทย | ลิงก์ของปุ่ม "เปิดหน้าแลกโค้ด" — เปลี่ยน `/th/` เป็น `/en/` ได้ |
| `watchEveryMin` | `120` | รอบของ `watch` |
| `maxInvalidPerDay` | `5` | หน้าเว็บแสดงจำนวนโค้ดผิดของวันนี้เทียบกับเลขนี้ (โหมด auto: หยุดเมื่อถึง) |
| `sources` | 10 แหล่ง (Garena 6 · Global 4) | `{ name, url, auto, enabled, match }` — `"enabled": false` ปิดแหล่งนั้น · `match` เป็น regex เช่น `"^GARENA"` · ชื่อที่ขึ้นต้นด้วย `Garena` ถูกจัดไว้หน้าคิว |
| `browser` `headless` `delayBetweenCodesSec` `maxCodesPerRun` `maxTriesPerCode` `loginWaitMin` `keepLoginDays` `rejectOptionalCookies` | | ใช้เฉพาะโหมด auto |
